Esta estrutura permite avaliar uma condção e executar um conjunto de
instruções caso a condição seja verdadeira e outro conjunto
de instruções, caso a estrutura seja falsa. Em JavaScript,
essa estrutura é formada pelos comandos if/else.
 if (condicao) {
    // instrucoes executadas caso a condicao seja verdadeira

 } else{
    //instrucoes executadas caso a condicao seja falsa
 }
