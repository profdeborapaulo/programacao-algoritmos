// Operadores e Tipos de Dados
Aritméticos
+ para Somar
- para Subtrair
* para Multiplicar
/ para Dividir
% para calcular o resto da divisão (modulo)
= atribuição

Relacionais:
> Maior que
< Menor que
>= Maior ou igual a
<= Menor ou igual a
== Igual a
!= Diferente de
=== igualdade estrita (Compara tanto o valor quanto o tipo de dado)
!== Diferença estrita (Compara tanto o valor quanto o tipo de dado)

// Operadores Lógicos:
$$ - E, retorna true se ambas as expressões são verdadeiras
|| - Ou, retorna true se pelo menos uma das expressões é verdadeira
! - Não, nega uma expressão lógica(booleana)
