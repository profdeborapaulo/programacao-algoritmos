Desenvolver um programa em JS que receba dois valores para as variáveis: num1 e num2. O objetivo do programa é realizar a troca de valores, manipulando  os dados das variáveis. Obrigatoriamente você deverá criar uma terceira variável para realizar essa troca. Exibir os valores iniciais para os valores num1 e num2, e ao final os valores trocados. Fazer em JS 3 no Draw.io o fluxograma.
