Esta estrutura permite avaliar uma condição e executar um conjunto de instruções caso a condição seja verdade3ira e outro conjunto de instruções caso a estrutura seja falsa em JavaScript, essa estrutura é formada pelos comados if e else.
Sintaxe:
if (condicao) {
    //instrucoes executadas caso a condicao seja verdadeira
} else {
    //instrucoes executadas caso a condicao seja falsa
}
